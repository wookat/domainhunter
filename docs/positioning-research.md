# DomainHunter 定位与竞品调研（2026-08）

老板问题：「从需求/寓意出发理解客户、给出真正可注册的域名」——我们是不是独一份？

## 结论（一句话）

**不是独一份，但在「中文市场 + Agent 多轮反思闭环 + 免费开源 + 全工具链」这个组合上目前没有对手。**
「描述创意 → AI 生成 → 实时核验可注册」这个基础形态在英文市场 2024–2026 已出现一批小型竞品，且 GoDaddy 等注册商也上了 AI 搜索；但它们全部是单轮生成、英文为主、免费额度极低（2–5 次/天）、无监控/清单/比价等配套。

## 真正的差异化（护城河候选）

1. **Agent 多轮反思闭环**：竞品都是「一次生成一批+核验」，被注册了就完；我们把已注册名单喂回下一轮让 AI 反思共性再造词，直到凑够可注册目标数——这是老板最初定义的核心，目前调研范围内独有。
2. **中文市场空白**：国内没有成熟的「自然语言→AI→实时核验」产品（Elysia 是≤10个名的小工具、关键词输入；Dynadot 面向域名投资人）。我们的双语+拼音/中文语感风格微调是独有组合。
3. **免费+开源 vs 竞品收费墙**：DotFind $9/mo、NameUnlock credit 制、免费额度 2–5 次/天；我们 20 次/小时 + 无限 quick-check/变体/批量。开源（MIT）在这个品类无第二家。
4. **全工具链**：锁定定向再猎、清单/同步码/分享、掉落监控+webhook、30 TLD 实时比价+续费陷阱、SEO 内容生态。竞品最多有其中一两样（多数还要付费）。

## 目标客户与定位建议

- **首要**：中文创业者/独立开发者/出海团队——想名字最痛（好域名被占+中英文语感都要），且国内无同类。
- **次要**：英文 indie hacker / side project 人群——被 DotFind 等验证过付费意愿（$9/mo、$39 brand kit）。
- **定位一句话**：「说出你的想法，AI 猎手多轮反思，只给你真正能注册的好名字」——对标话术直接打「ChatGPT 推荐的域名都被注册了」+「其它工具只给一批就完，我们会反思重试直到够」。
