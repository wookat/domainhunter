DomainHunter · R2 UI 原型

静态 HTML 原型（Tailwind CDN + lucide CDN）。移动端为同一页面响应式布局，请以 375px 视口查看。设计规范见 ../design-spec.md。

  • ① 首页描述输入 + TLD 胶囊多选 + 风格 Select + 示例 chips
  • ② Agent 检索进行中需求理解确认 + 分轮时间线 + 名字/寓意先出 + 原位状态翻转
  • ③ 结果列表可注册优先 + 评分环/四维分 + 注册商下拉 + 复制/收藏/导出/再来一批
  • ④ 移动端布局上述三页均为移动端优先响应式；375px 截图见 ../screenshots/
