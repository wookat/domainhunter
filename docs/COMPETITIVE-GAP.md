# 竞品逐项对比清单（R5 → R6 输入）

> 对比对象：dotfind.ai（AI 域名生成器）、instantdomainsearch.com（即时域名搜索老牌）。
> 结论标注：✅ 领先 / ➖ 持平 / ❌ 落后。基于 2026-08 公开产品页与实际体验整理。

## 逐项对比

| 维度 | DomainHunter（R5） | dotfind.ai | instantdomainsearch.com | 结论 | 建议（R6） |
|---|---|---|---|---|---|
| **输入方式** | 自然语言描述 + 风格/长度偏好 + 自定义 TLD；高级模式支持词根×前后缀组合 | 自然语言 prompt + 关键词 | 单框关键词即时搜索，无语义输入 | ✅ 领先 | 保持；可加「行业模板」快捷入口降低首次输入门槛 |
| **生成能力** | DeepSeek 多轮反思式生成（最多 5 轮补缺口），每名附中文寓意解释 | AI 单轮批量生成，英文为主 | 无 AI 生成，仅前后缀机械变体 | ✅ 领先（中文语境）| 英文命名质量需专项调优（面向 EN 用户） |
| **可用性核验** | RDAP + DNS(DoH) 双通道 + WHOIS 兜底，流式返回；KV 缓存（available 1h / taken 24h）；清单页可缓存穿透复查 | 核验有延迟，部分结果需点击后二次确认 | 即时核验（其核心卖点），毫秒级 | ➖ 持平（比 dotfind 强，比 IDS 首字节慢）| 预热热门 TLD、并发调大；输入即查（防抖）做「秒出」体感 |
| **结果呈现** | 四维评分（长度/读感/寓意/品牌感）+ Top Picks + 行/卡片双视图 + 键盘导航 + 已注册折叠区 | 简单列表 + 收藏 | 分区列表（精确/变体/后缀），无评分 | ✅ 领先 | 保持；评分依据可展开解释增强可信度 |
| **收藏/清单** | localStorage 候选清单 + 对比表 + 状态复查（掉落/回补高亮）| 需注册账号收藏 | 无收藏 | ✅ 领先（免登录）| 增加跨设备同步（可选轻账号或分享链接即同步） |
| **导出** | CSV / TXT 双格式，结果页与清单页均可 | 无导出 | 无导出 | ✅ 领先 | 保持 |
| **分享** | R5 新增：清单快照分享链接（30 天有效，只读页 + CTA）| 无 | 无 | ✅ 领先 | 加 OG 动态图（清单预览图）提升社交转化 |
| **价格信息** | 主流 TLD 首年/续费参考价（静态表，人民币） | 无价格 | 实时注册商价格 + affiliate 直跳 | ❌ 落后（静态 vs 实时）| R6 接注册商价格 API（Porkbun/Namecheap 公开价）做实时价 + 比价 |
| **注册通道** | 阿里云/腾讯云/Namecheap/Cloudflare 四注册商菜单直跳 | 单一注册商 | 多注册商 + affiliate | ➖ 持平 | 接 affiliate 变现；按用户语言默认注册商 |
| **移动端** | 响应式完整适配（44px 触控目标、卡片视图、375px 无横向溢出） | 移动端一般，部分控件过小 | 移动端可用但信息密度低 | ✅ 领先 | 保持；PWA 加装到桌面 |
| **性能** | Workers 边缘部署；首屏 JS ~112KB gzip；AI 生成为主要耗时（约 5–15s/轮，流式缓解） | AI 等待明显，>10s 无进度反馈 | 极快（无 AI） | ➖ 持平（体感取决于场景）| 骨架屏已有；可加首轮「快速模式」（少量候选先出） |
| **国际化** | R5 新增：中/英双语切换（localStorage 持久化） | 仅英文 | 仅英文 | ✅ 领先（双语） | EN 文案母语级润色；hreflang/SEO 分语言页 |
| **登录门槛** | 全功能免登录 | 收藏需登录 | 免登录 | ➖ 持平 | 保持免登录为卖点 |
| **SEO/着陆** | R5 补齐：完整 meta/OG/Twitter 卡 + 三步说明 + 累计核验数信任位 | 营销页完善、有博客内容 | 域名词权重极高、长尾页面多 | ❌ 落后（内容生态） | R6 做程序化 SEO：TLD 指南页、行业命名指南等长尾内容页 |

## 汇总

- **领先项（7）**：输入方式、生成能力（中文）、结果呈现、收藏/清单、导出、分享、移动端、国际化（双语）
- **持平项（4）**：核验速度体感、注册通道、性能、登录门槛
- **落后项（2）**：实时价格/比价、SEO 内容生态

## R6 优先级建议

1. **P0 实时价格 + affiliate**（补最大功能短板，同时打开变现）
2. **P1 程序化 SEO 内容页**（TLD 指南 / 行业命名长尾页，补流量短板）
3. **P1 输入即查体感优化**（热门 TLD 防抖即时核验，对标 IDS 核心卖点）
4. **P2 清单跨设备同步**（基于分享链接机制延伸，仍免登录）
5. **P2 EN 文案母语润色 + 分语言 SEO（hreflang）**
